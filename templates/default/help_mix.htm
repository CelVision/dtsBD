17.道具合成

可以将某些物品合成为另一种物品，只要名称正确即可合成。合成道具成功则可增加爆熟。

合成成功时，如果所用的材料是武器或者防具，则会将整个材料耗尽；其他情况下，材料的耐久会减1。

鼠标停留在参与合成的道具上可以显示此道具获取方式。

表记为头衔奖励相关道具的条目，其合成素材将来源于头衔奖励。

同调合成与超量合成说明：

游戏王系道具名字后面带有‘★ 数字’的道具可以参与同调合成。只要你选择的道具均可以参与同调合成，且至少存在一个道具含有“调整”属性，同调合成就能进行。
若干同调道具合成时，会对‘★’后面的数字求和，不妨设结果为x，那么合成结果就是星数为x的道具，如果有多种，你可以从中任选一个作为结果。
总之，同调合成就是算星数的和。 只要参与合成的道具都具有星数，且至少存在一个道具具有调整属性，也存在对应星数的合成结果，就能成功合成。
例如：卡片汽车 D ★2 + 水灵使-艾莉娅 ★3 + 盟军 次时代鸟人 ★3（这个道具具有调整属性） => 星尘龙 ★8
或者：救世龙 ★1（这个道具具有调整属性） + 凭依装着-希塔 ★4 + 光灵使-莱娜 ★3 => 星尘龙 ★8

道具属性中带有超量素材属性的道具可以进行超量合成。装备具有“多重”属性且具有星数的投系武器，点击“武器模式”按钮，即可将武器转化为超量素材。注意，转化是不可逆的！
超量合成要求所有参与合成的道具都是超量素材，且星数相同。 参与合成的超量素材的星数和个数决定了合成结果，与同调一样，如果有多个，你可以从中任选一个。
